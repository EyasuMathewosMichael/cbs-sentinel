# Testing and Certification Requirements

Any approved bank adapter must pass the same contract tests as the simulator and placeholder adapter.

## Required validation

- unit tests
- integration tests
- contract tests
- fault-injection tests
- duplicate request tests
- timeout/unknown tests
- reconciliation tests
- reversal tests
- security tests
- performance tests

## Production gate

No bank adapter may be marked production-ready without approval and test evidence from the bank and the SENTINEL operator.
